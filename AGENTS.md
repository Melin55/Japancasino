# Working in this repository

- Read `README.md` before starting. This is a static starter, not a completed application.
- Keep setup reproducible and avoid adding dependencies unless the requested work needs them.
- Use the existing checkout in an isolated Codex cloud task. Do not create Git worktrees unless the user explicitly asks.
- Preserve existing user changes. Do not force-push or overwrite another task's work.
- For normal development, use a task branch and a pull request; report changes, checks, and remaining work in the PR.
- Never commit credentials, `.env` files, or local logs.
- Validate static changes by starting the server documented in `README.md` and checking the affected resources with HTTP requests. Report unrun tests honestly.
