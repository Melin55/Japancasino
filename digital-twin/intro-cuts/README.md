# 紹介動画のコマ01・03・06

別の制作工程で生成された手元動画2本を確認して再利用し、正式ロゴの6秒エンドカードを作る工程です。社長の出演、発話、音楽、字幕は追加しません。従来のデジタルツイン動画とは別の素材です。

## 入力と出力

`project.json` に、元動画のパス・採用フレーム範囲と、学校公式PDF内のロゴのページ番号・矩形を記録します。モデル・動画・PDF・生成したPNG等はGit外に保存します。元動画の実測値は768×1344・24fpsで、01は124フレーム、03は328フレームです。コンテナに音声が入っているため、見かけの長さと映像の長さは異なります。

- 01：フレーム28〜123の96フレームを採用。カードを置き終える動作を含む4秒。
- 03：フレーム0〜311の312フレームを採用した13秒。約5.7秒の既存ハードカットを保持。
- 06：1080×1920・24fps・144フレーム・6秒。白背景に公式ロゴを中央配置し、最初の12フレームでフェードイン。その後は静止し、フェードアウトしません。

01・03は速度を変えず、左右を6pxずつ切って756×1344の9:16へ整え、1080×1920へ拡大します。手元とカードが切れないことを確認した素材専用の範囲です。新しい生成やAIアップスケールは行いません。実校・実授業の記録ではなくAIイメージとして扱います。カードの細かな印刷などは実写相当の精度を保証しません。

06は[学校公式の募集要項PDF](https://casinoschool.co.jp/wp-content/uploads/2022_boshu_online-1.pdf)の表紙にあるロゴだけを、元のベクトルパス・色・比率を保って切り出します。年月や連絡先は含めません。企業ロゴを生成モデルやフォントで描き直す処理はありません。白背景はブランドマニュアル未提供時の制作案です。

## 再編集

Python 3、FFmpeg/ffprobe、Pillow、PyMuPDFが必要です。制作時はPillow 12.3.0、PyMuPDF 1.26.6を使用しました。素材入りの納品ZIPには `render.py`、`project.json`、`sources/`、`assets/`、`exports/`、`scenegraph-cut-06.json`、検証記録を含みます。

```sh
python render.py --project /path/to/project.json
```

再出力時は `render.py`・`project.json`・`sources/` を新しいフォルダへコピーして実行してください。既存のMP4は上書きしません。ロゴ、背景、動画、動きは階層JSONで分けて参照できます。生成に用いたリンクだけでなく、入手した元素材もZIPの `sources/` に保存しています。

## 検証

元素材は毎秒と手・カードの接触箇所を画像で確認します。出力のフレーム数、解像度、fps、音声ストリームがないこと、全体デコードを検査します。06はデコードした最後72フレームのハッシュがすべて一致することを確認し、最後3秒の完全な静止保持を検証します。毎秒の画像だけで動作全体の自然さを保証するものではありません。
